基準値 あなた専用の目安（この端末の人だけに適用）

空欄の基準は「現状の値」で計算します。ここで設定した基準値は、あなた個人の目標計算にだけ使われ、他のメンバーには影響しません。 チーム共通の目安は 対応アプ率 15%／アプアポ率 40%／出勤アポ率 2.5件／商談アポ率 25%／商談完工率 40% です。

歩留まり診断 現状 vs 基準値

「現状ペース」は現状の1日あたり実績を出勤予定日数に換算した数。「必要数」は基準値の歩留まりで目標完工数に届くための数。バーは充足率です。

鬼速PDCAで課題を回す

ゴール（KGI）とのギャップから課題を最大3つに絞り、KPI（数値）→ 解決案 → DO（行動）まで落とし込みます。 歩留まりだけでなく、フェーズの内訳（インターホン〜アポ）と〇△✖アポもKPIに選べます。 ここで決めた課題は、④の週次PDCAで「②の課題から取り込む」を選ぶと、その週のDOとして検証できます。

  1. P 計画KGI → ギャップ → 課題（最大3つ）→ KPI化
  2. D 実行解決案 → DO → TODO（毎日／期限付き）
  3. C 検証KPI達成率 × DO実行率で要因を見る
  4. A 調整できた要因・できなかった要因 → 調整案

フェーズの目標と週次PDCA

フェーズごとの内訳と〇△✖アポについて、目標と現状のギャップを出し、どの数字をどれだけ上げれば届くかを示します。 そのギャップごとにKGIとKPIを立て、週に最大3つまで解決策とDOを決めて、検証（C）と調整（A）をおこないます。 振り返りは土日の出勤も含めた1週間（土〜金）ぶんを、翌週の平日に1回です。

  1. P 計画KGI → ギャップ → KPI（フェーズ構成比）
  2. D 実行週に最大3つの解決策 → DO
  3. C 検証KPI達成率 × DO実行率で要因を見る
  4. A 調整継続・修正・中止 → 来週へ引き継ぐ

項目ごとの目標と現状 目標は構成比（％）で入れます。実績は営業ログの日報から自動で集計します

インターホン・フロント・対象確認は割合が下がるほど良い、ニーズ・アプ・アポと〇アポは上がるほど良い項目です。 「残りで必要」は、残りの出勤日で今月の目標件数に届かせるために必要な数字です。
